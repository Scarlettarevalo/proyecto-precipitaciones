# 🌧️ Monitoreo Hídrico y Proyección de Precipitaciones

Aplicación interactiva desarrollada en Python y Streamlit para analizar la evolución histórica de precipitaciones en Chile (2010–2025) y proyectar escenarios futuros mediante modelos matemáticos.

## 📁 Estructura del Proyecto
- `app.py`: Dashboard interactivo principal.
- `forecasting.py`: Modelos de proyección matemática (Regresión Lineal y Promedio Móvil).
- `datos/`: Dataset histórico de precipitaciones.
- `src/`: Módulos del pipeline de procesamiento (`carga.py`, `limpieza.py`, `transformacion.py`, `analisis.py`, `reporte.py`).
- `reportes/avance_4.pdf`: Informe técnico computacional.
